# DeepChat GPUI

A native Rust + GPUI reimplementation of DeepChat.

The frozen product baseline is DeepChat `v1.1.1` at commit `ca75acfdc680fa3d0a2bbde13575fa711d08a3bd`. See [PORTING.md](PORTING.md) for scope, verification rules, and recovery instructions.

## Status

The port is under active development. Feature status is tracked only in [parity/manifest.json](parity/manifest.json); no incomplete area is represented as production-ready.
